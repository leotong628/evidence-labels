# evidence-labels

An Agent Skill that prompts an AI agent to label decision-relevant factual claims as measured, inferred or assumed.

A skill is instructions in a file. It guides an agent; it does not enforce anything.

## Install

```
npx skills add leotong628/evidence-labels
```

Or copy `skills/evidence-labels/` into `~/.claude/skills/` (or `.claude/skills/` in a project). For Claude.ai, zip the `evidence-labels` folder and upload it.

`npx` runs a separately fetched third-party command that this project has not audited. Prefer copying the files from a tagged release.

## What is in it

One short `SKILL.md` (see `skills/evidence-labels/SKILL.md`). No scripts, no dependencies.

## Status

Version 0.1, written from daily use and reviewed before publication. It has not yet been tested against a baseline with formal evals; treat it as a working draft and open an issue with what you see.
